# 需求规格说明书 — Trae Work 助手 v1.0.0

> **版本**: v1.0.0 | **状态**: 已完成 | **完成日期**: 2026-08-13
>
> 配套文档：`product-design.md`（完整交互/界面/数据模型）。本文档聚焦「可确认、可验收」的需求条目。
> 范围：本期仅实现桌面端管理工具（v1.0）。v2.0 本地 API 网关已实现（详见 requirements-v2.md）。

## 1. 背景与目标

将签到、代理捕获、账号切换、设备隔离等能力收敛到一个简约美观的 Windows 桌面端应用中，支持账号分组批量运营。

**目标**：一体化、低门槛、可运营、可维护、可演进。

## 3. 用户故事（核心）

- **作为新用户**，我希望 5 步内完成首个账号接入（检测 TW→装 CA→启代理→登录→入库），以便快速上手。
- **作为重度用户**，我希望勾选一组账号一键签到并看到实时进度，以便每日批量运营。
- **作为运营用户**，我希望按分组（主力/备用/测试）管理账号并批量操作，以便区分用途。
- **作为普通用户**，我希望 JWT 临期时被提醒并一键续期，以便账号持续可用。

## 4. 边界与约束

- **不做**：v2.0 API 网关不在本期；v2.0 API 网关已实现，详见 requirements-v2.md。
- **平台**：Windows 10 1809+ / Windows 11；支持 100%~200% DPI。
- **复用**：核心逻辑由现有 `auto_checkin.py` / `device_proxy.py` 与 PowerShell 切换器承担，UI 仅调度与展示。
- **兼容**：`checkin_accounts.json` / `device_map.json` 保持原结构，用户仍可直接跑原脚本。
- **安全**：JWT 明文存用户数据目录（继承现状）；展示仅脱敏；配置导出 AES-256-GCM 加密；仅 CA 安装/机器码重置/计划任务注册三类操作提权。

## 5. 验收总览（P0 的 Given-When-Then）

- **GIVEN** 应用启动 **WHEN** Trae Work 未安装 **THEN** 显示未安装并引导官网。
- **GIVEN** 代理已启动且 TW 走代理登录 **WHEN** 用户登录账号 **THEN** 账号自动入库并出现在列表。
- **GIVEN** 勾选 3 个账号 **WHEN** 点击批量签到 **THEN** 逐账号实时结果，失败项不阻断其余。
- **GIVEN** 某账号 JWT 临期 **WHEN** 用户点续期 **THEN** 启动代理并切换，捕获新 JWT 后 exp 延长。
- **GIVEN** 选中账号点切换 **WHEN** 确认 **THEN** TW 重启后该账号为`当前`，无验证码。
